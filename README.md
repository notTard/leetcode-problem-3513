# leetcode-problem-3513
решение  проблемы №3513 из leetCode

# Дано

- Массив nums длины n, который является перестановкой чисел от 1 до n

- Нужно рассмотреть все тройки индексов (i, j, k) где i ≤ j ≤ k (нестрогое возрастание)

- Для каждой тройки вычисляем XOR трех элементов: nums[i] XOR nums[j] XOR nums[k]

- Нужно посчитать количество уникальных значений XOR, которые можно получить

# Объяснение

Для массива nums длины n (перестановка чисел 1 до n):
Если n нечетное: можно получить ВСЕ числа от 0 до 2^k - 1, где k это n в двоичной системе(количество бит).
Если n четное: можно получить ВСЕ числа от 0 до 2^k - 1, где k = тоже n в двоичной системе, кроме случая n = 2.

**Когда n нечетное, XOR всех чисел от 1 до n дает 0 (потому что пары (1⊕2⊕3⊕...⊕n) = 0 для нечетного n)
Когда n четное, XOR всех чисел дает n (для четного n)**

Но главное: наличие числа n определяет, какой старший бит доступен.

# Алгоритм
Найти k = количество бит в n 
Если n == 2 → ответ = 2(исключение)
Иначе ответ = 2^k
